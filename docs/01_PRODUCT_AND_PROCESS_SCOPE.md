# Product and Process Scope

## Product objective

Replace paper registers, disconnected spreadsheets and manual follow-up with one reliable digital operating system. Reduce school office work, reuse information once, and stay simple for staff and parents using lower-cost phones or unstable networks.

## User roles

| Role               | Primary jobs                                               |
| ------------------ | ---------------------------------------------------------- |
| Principal          | approvals, operational dashboard, compliance, exceptions   |
| Administrator      | academic masters, student records, notices, reports        |
| Admissions officer | applications, documents, review, onboarding                |
| Accountant         | fee plans, invoices, collections, receipts, reconciliation |
| Teacher            | attendance, homework, marks for assigned classes/subjects  |
| Parent/guardian    | application, fees, attendance, notices, homework, results  |
| Student            | homework, timetable, published results and notices         |
| Transport manager  | routes, stops, vehicles, student assignments               |

## Core lifecycle

```text
Academic year/classes/sections/subjects/teacher assignments
  -> Admission application + guardian verification + documents + consent
  -> Review / approve / reject / waitlist
  -> Student + guardian + enrollment
  -> Fee invoices / attendance roster / communication eligibility
  -> Homework / marks / report card
  -> Promotion / transfer certificate / archive
```

## Product boundaries

MVP includes academic/student masters, admissions/onboarding, fees/payments, attendance, communication, homework, exams/report cards, reports and transport after core stability. Later modules require an approved change request: multi-school operations, payroll/HR, hostel/library/inventory, biometric/RFID, AI grading, surveillance or targeted advertising.

## Success measures

- Admission application to enrolled student without duplicate typing
- Teacher can mark a standard class attendance session in under 30 seconds under normal connectivity
- Parent can view/pay fees with clear receipt and status
- Report-card generation is asynchronous, traceable and publishable only by authorized staff
- Staff use the system for daily work rather than parallel paper/Excel records
- No unauthorized parent, teacher or role can access another person’s data
