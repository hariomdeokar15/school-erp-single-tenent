# Project Tracking and Governance

## Required registers

Product backlog, ADR/decision log, risk register, data field register, permission matrix, requirements traceability, test evidence, release register and incident register.

## ADR template

```markdown
# ADR-XXX — Title

Status: Proposed | Accepted | Superseded
Date:
Owner:

## Context

## Decision

## Alternatives

## Consequences

## Security/privacy impact

## Validation/review date
```

## Definition of done

Code, tests, review, localization, documentation, security controls and operational visibility complete. “Works on my machine” is not done.

## Change control

Schema, payment, permission, consent, audit, retention, provider integration and production infrastructure changes require an ADR/documented change request plus human approval.
